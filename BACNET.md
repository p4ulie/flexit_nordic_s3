# BACnet on the Flexit Nordic

This document explains the protocol the unit speaks: just enough BACnet to read [ENDPOINTS.md](ENDPOINTS.md), debug with Wireshark, or write a client without `flexit-bacnet`.
For setup and usage, see [README.md](README.md).

The Nordic's controller is a Siemens unit; its BACnet vendor ID is 7. It speaks standard **BACnet/IP**, defined in ASHRAE 135, Annex J.

## Transport

| | |
|---|---|
| Protocol | UDP, port **47808** (`0xBAC0`), on both ends |
| Encryption / auth | none: anyone who can reach the port can read and write |
| Request model | one datagram request → one datagram reply, matched by invoke ID |
| Addressing | the request is sent unicast to the unit's IP address |
| Discovery | broadcast to `255.255.255.255:47808` (see [Discovery](#discovery)) |

UDP is connectionless, so the reply has to be able to reach you. Run clients on the unit's subnet, or make sure no NAT or firewall
drops the reply. `flexit-bacnet` waits 1 s for each reply. `flexit.py` gives the whole read 15 s.

## Concepts

- **Device.** The unit itself is one BACnet device, identified by a **device instance**: the "Device ID" in Flexit GO, e.g. `2`.
  Requests are addressed by IP address, so the device instance isn't in the packets below. `flexit-bacnet` uses it only to read
  the device object's name and description (`device,<id>`).
- **Object.** Each data point is an object, identified by **type + instance**, e.g. `multi-state-value,42`. All 653 are listed in [ENDPOINTS.md](ENDPOINTS.md).
- **Property.** Each object has properties. The ones that matter here:

  | Property | ID | Meaning |
  |---|---:|---|
  | `present-value` | 85 | the value; what you read and write |
  | `object-name` | 77 | short name |
  | `description` | 28 | human-readable description (the text in ENDPOINTS.md) |
  | `units` | 117 | engineering unit |
  | `state-text` | 110 | names of the states of a multi-state value |
  | `priority-array` | 87 | the 16 command slots (see below) |
  | `relinquish-default` | 104 | value used when all 16 slots are empty |

### Object types

| Object type | ID | `present-value` datatype | Writable here |
|---|---:|---|---|
| `analog-input` | 0 | REAL | no (sensor) |
| `analog-output` | 1 | REAL | no in practice (actuator signal) |
| `analog-value` | 2 | REAL | some (setpoints) |
| `binary-input` | 3 | ENUMERATED | no |
| `binary-output` | 4 | ENUMERATED | no in practice |
| `binary-value` | 5 | ENUMERATED: `0` inactive, `1` active | some |
| `device` | 8 | n/a | no |
| `multi-state-value` | 19 | UNSIGNED: states numbered from **1** | some |
| `positive-integer-value` | 48 | UNSIGNED | some (runtimes) |

A write must use the matching datatype. A REAL sent to a multi-state value is rejected.

### Command priority

A commandable object doesn't hold one value: it holds a **priority array** of 16 slots. `present-value` is the value in the
lowest-numbered (most important) slot that isn't empty. If all slots are empty, it falls back to `relinquish-default`.

- A WriteProperty with priority *N* fills slot *N*. Writing `NULL` to slot *N* **relinquishes** it, so the next slot takes over.
- A write with no priority goes to slot **16**, the lowest.
- **Flexit's mode objects are written at priority 13** (`binary-value,50`, `multi-state-value,42`, `binary-value,402`).
  If you write them at another priority, you either get overridden by slot 13, or your value sticks in a more important slot
  and silently overrides the app and the panel until you relinquish it.
- Setpoints and runtimes aren't written with a priority, so they go to slot 16.

## Services used

| Service | Type | Choice | Used for |
|---|---|---:|---|
| ReadPropertyMultiple | confirmed | 14 | one request reads every point (`flexit.read()`) |
| WriteProperty | confirmed | 15 | every control action |
| UnconfirmedPrivateTransfer | unconfirmed | 4 | Siemens discovery (vendor 7) |
| ReadProperty, Who-Is/I-Am | — | 12, — | not used by `flexit-bacnet`. Generic tools such as `bacrp`, `bacwp` and BAC0 rely on them |

Generic tools find a device by its device instance using **Who-Is**. Whether the unit answers Who-Is hasn't been tested.
If a tool can't find it, discover the IP address as described below and give the tool that address directly.

## Packet anatomy

Every datagram has three layers. The bytes below are generated by `flexit-bacnet`'s own encoder.

```
BVLC (4)        NPDU (2)   APDU
81 0a LL LL     01 04      ...
│  │  └ total datagram length
│  └ 0x0a Original-Unicast-NPDU (0x0b = Original-Broadcast-NPDU)
└ 0x81 BACnet/IP
                 │  └ 0x04 expecting reply
                 └ version 1
```

A confirmed request APDU starts with `02 44 01 <service>`. That means:

- `0x02`: confirmed request, segmented response accepted.
- `0x44`: up to 16 segments, max APDU 1024 bytes.
- `0x01`: the invoke ID, which the library keeps fixed at 1.

### Read the operation mode (ReadPropertyMultiple)

```
81 0a 00 13  01 04  02 44 01 0e  0c 04 c0 01 69  1e 09 55 1f
                                 │               └ list of properties: [present-value (0x55 = 85)]
                                 └ object id: type 19 << 22 | 361 = 0x04c00169 → multi-state-value,361
```

The reply is a ComplexACK (`30 01 0e …`). It carries the same object id, then the value.

### Set ventilation mode Home (WriteProperty, priority 13)

```
81 0a 00 17  01 04  02 44 01 0f  0c 04 c0 00 2a  19 55  3e 21 03 3f  49 0d
                                 │               │      │            └ priority 13
                                 │               │      └ value: UNSIGNED 3 (Home)
                                 │               └ property 85 (present-value)
                                 └ multi-state-value,42
```

### Comfort button on

```
81 0a 00 17  01 04  02 44 01 0f  0c 01 40 00 32  19 55  3e 91 01 3f  49 0d
                                 binary-value,50        ENUMERATED 1   priority 13
```

### HOME setpoint 21.0 °C (no priority → slot 16)

```
81 0a 00 18  01 04  02 44 01 0f  0c 00 80 07 ca  19 55  3e 44 41 a8 00 00 3f
                                 analog-value,1994      REAL 21.0 (IEEE 754 big-endian)
```

A successful write is answered by a **SimpleACK**: APDU `20 01 0f`.
A rejected write returns an **Error** PDU (`50 …`) with an error class and code, e.g. *property / write-access-denied*.

To see these bytes on the wire, run any `flexit-bacnet` code with `DEBUG=1` set. It prints each request and response as hex
(`>>>` / `<<<`) for reads. Wireshark decodes UDP 47808 as BACnet with no setup.

## Discovery

The Flexit GO app finds units by broadcasting a Siemens-proprietary **UnconfirmedPrivateTransfer**: vendor 7,
service **515** ("discover"), and its payload contains the string `?Devices=All`. Each unit answers with service **516** (identification) from its own IP address.
`flexit_bacnet.discover()` replays a captured copy of that request. To use it:

- Bind UDP 47808 locally. Only one process can hold the port, so stop other BACnet clients first.
- You get back IP addresses only. Read the device instance from Flexit GO (see [README.md](README.md#finding-the-connection-parameters)).
